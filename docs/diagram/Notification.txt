title Notification

participant Client
participant Socket
participant NotificationHandler
participant Redis

note over Client,Socket: 1. 소켓 연결 설정
participant DB
participant External

Client->>Socket: 소켓 연결 요청 (/notifications 네임스페이스)
Socket->>Socket: authSocketMiddleware 실행
Socket->>DB: 사용자 정보 확인
DB-->>Socket: 사용자 정보 반환
Socket-->>Client: 소켓 연결 성공
Socket->>Redis: 소켓 연결 정보 저장

note over Client,Socket: 2. 알림 목록 요청
Client->>Socket: "GET_NOTIFICATIONS" 이벤트
Socket->>NotificationHandler: 알림 목록 조회 처리
NotificationHandler->>Redis: 캐시된 알림 확인

alt 캐시 있음 & 유효함
    Redis-->>NotificationHandler: 캐시된 알림 반환
else 캐시 없음 또는 만료됨
    NotificationHandler->>DB: 데이터베이스에서 알림 조회
    DB-->>NotificationHandler: 알림 목록 반환
    NotificationHandler->>Redis: 알림 캐싱
end

NotificationHandler-->>Client: "NOTIFICATIONS_LIST" 이벤트로 알림 전송

note over Client,Socket: 3. 새 알림 발생 (e.g. 친구 요청)
DB->>NotificationHandler: sendNotification() 호출
NotificationHandler->>DB: 알림 DB에 저장
DB-->>NotificationHandler: 저장된 알림 정보
NotificationHandler->>Redis: 알림 관련 데이터 캐싱 갱신
NotificationHandler->>Redis: 수신자 연결 상태 확인

alt 수신자 온라인
    NotificationHandler->>Socket: 실시간 알림 전송
    Socket-->>Client: "NOTIFICATION" 이벤트
else 수신자 오프라인
    NotificationHandler-->>DB: 추후 확인할 수 있도록 저장만 유지
end

note over Client,Socket: 4. 알림 응답 처리 (e.g. 친구 요청 수락/거절)
Client->>Socket: "NOTIFICATION_RES" 이벤트
Socket->>NotificationHandler: 알림 응답 처리
NotificationHandler->>DB: 알림 상태 업데이트

alt 친구 요청 수락
    NotificationHandler->>External: 친구 API 호출 (친구 관계 생성)
    External-->>NotificationHandler: API 응답
    NotificationHandler->>DB: 상대방에게 친구 수락 알림 생성
    NotificationHandler->>Redis: 관련 캐시 삭제
    NotificationHandler->>Socket: 상대방에게 친구 수락 알림 전송
else 게임 초대 수락
    NotificationHandler->>Client: "GAME_INVITE_ACCEPTED" 이벤트
end

NotificationHandler-->>Client: "NOTIFICATION_RES_SUCCESS" 이벤트
